# Profile activity

The activity graphics are generated by `scripts/update_profile_activity.py` using Python's standard library and the GitHub API. They do not depend on a public third-party stats-card server.

The GitHub Actions schedule is twice daily at 03:23 and 15:23 UTC (08:53 and 20:53 Asia/Kolkata), plus manual dispatch and changes to the generator/workflow. Scheduled jobs can run late; this is a 12-hour target, not a real-time guarantee. The schedule is active once this workflow lands on the default branch. No external monitor or local background task is installed.

The workflow uses the job's built-in `GITHUB_TOKEN`, limited to writing this profile repository. No personal access token or extra secret is required for public statistics. It commits only five generated assets, using the GitHub Actions bot identity, and never modifies the README, project entries or other repositories. Protected-branch or token-policy failures must be reported, not bypassed. No workflow executes on pull-request events or untrusted forks.

## Metrics

- **Contributions · past year:** the contribution-calendar total for the displayed GitHub period. It includes activity in owned projects and follows GitHub's contribution rules; it is not a merged-PR count.
- **Longest daily streak · past year:** the longest consecutive run inside the displayed calendar window; not an all-time claim.
- **Current daily streak:** consecutive active dates ending today, or yesterday if today's calendar date is still empty. It uses GitHub's returned calendar dates, not invented activity or an independent timezone rebucketing.
- **Authored merged PRs:** public, merged pull requests authored by Pratham2511, excluding repositories owned by Pratham2511. All-time within GitHub's searchable public history.
- The distinct external repository count remains metadata only; it is not a displayed counter. Assignment requests, peer reviews, comments, closed-unmerged PRs and own-project PRs do not inflate authored merged PRs.
- **Top external repositories:** individual repositories ranked by the same merged authored PR count; ties sort by full repository name. CODERCOPS projects are separate repositories, not silently pooled into one.
- **Open PRs:** a count only of open public PRs authored by Pratham2511 to external repositories. Individual titles/links are not displayed or retained in the generated summary.

The contribution coordinator's 47 accepted contributions include three maintainer-authored landing PRs credited to Pratham, so that separate historical record can exceed this standard authored-PR statistic (44 at the preview). Those records are not changed or mislabelled. Generating a profile graphic does not resume retired project work.

The generator checks complete pagination and calendar/identity integrity. API errors, changing pagination counts or more than 1,000 matching PRs fail the job instead of publishing truncated totals or zeros. Existing published graphics remain until a successful update. There is no displayed contribution-calendar grid or peer-review statistic. Graphics have transparent backgrounds with dark/light text versions and narrow-layout variants. They contain no executable content or external asset requests. A README cannot force GitHub’s page theme or outer background. Only aggregate/public display data is stored in `assets/profile-activity.json`.

For an offline preview, pass a captured public API response with `--input-json PATH` and optionally `--updated-at ISO_TIMESTAMP`. Never commit API tokens or raw authenticated responses. A local render is not proof that a hosted run succeeded; confirm the current run in the repository Actions tab.
