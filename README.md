## Selected work

### TGDetect

**Temporal graph security detection and investigation platform.** Turns raw cybersecurity telemetry into temporal heterogeneous graphs, attack chains, and forensic investigation surfaces. The detection pipeline combines GraphSAGE with a GRU for multi-stage threat analysis while keeping live telemetry separate from offline benchmark metrics.

`Python` · `PyTorch` · `PyTorch Geometric` · `FastAPI` · `Next.js` · `GraphSAGE`

[Source →](https://github.com/Pratham2511/TGDetect-Temporal-Graph)

### Verbis

**AI database assistant inside VS Code.** Converts natural-language questions into SQL/NoSQL, supports schema exploration and ER diagrams, maintains query history, and includes privacy controls such as PII masking and schema anonymization. Supports PostgreSQL, MySQL, SQLite, Gemini, Groq, and local Ollama workflows.

`TypeScript` · `React` · `Python` · `FastAPI` · `VS Code Extension API`

[Source →](https://github.com/Pratham2511/Verbis-Intelligent-Database-Assistant) · [Product page →](https://verbis-lp.vercel.app/)

### ScholarNexus — The Evidence Desk

**Local-first workspace for scholarly discovery and literature review.** Searches academic providers directly, preserves source passages with provenance, supports screening and evidence matrices, exports reproducible research records, and keeps the baseline workflow usable with AI disabled.

`Next.js` · `TypeScript` · `PostgreSQL` · `Prisma` · `Research APIs`

[Source →](https://github.com/Pratham2511/Kivo-Research-Discovery-Workspace)

### ShetVaidya

**Location-aware AI crop-disease analysis and medicine verification platform.** Combines MobileNetV2 inference with a FastAPI backend, authenticated scan history, image storage, and medicine verification in a production-oriented multi-service architecture.

`React` · `FastAPI` · `TensorFlow` · `PostgreSQL` · `Redis` · `Cloudflare R2`

[Source →](https://github.com/Pratham2511/ML-Based-plant-disease-analysier-) · [Live →](https://ml-based-plant-disease-analysier.vercel.app/)
